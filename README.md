# Linear_Regression
# Linear Regression Model Deployment

This project demonstrates the deployment of a Linear Regression Machine Learning model using Streamlit. The model was trained in Google Colab and saved as a pickle file (`model.pkl`).

## Features

- Linear Regression Model
- Streamlit Web Application
- Real-time Predictions
- Model saved using Pickle
- Version controlled with Git & GitHub

## Technologies Used

- Python
- Scikit-Learn
- NumPy
- Pandas
- Streamlit
- Pickle

## Project Structure

```text
.
├── app.py
├── model.pkl
├── requirements.txt
└── README.md
```

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
